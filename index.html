CONCEITOS ESSENCIAIS

O que está por trás?

Conheça os conceitos trabalhados
neste laboratório.

↔

Criptografia

Transforma uma mensagem para que ela possa ser recuperada usando uma chave ou regra.

#

Hash

Gera um resumo de tamanho definido. Não é um processo reversível como a criptografia.

✳

Salt

Valor aleatório adicionado ao processo de proteção de senhas para evitar hashes idênticos.

⌁

Autenticação

Confere se as credenciais apresentadas correspondem às informações cadastradas.

!

Aprender segurança também é praticar com responsabilidade.

Este projeto é educativo. A cifra de César é fácil de quebrar e SHA-256 simples não é indicado para armazenar senhas. Em sistemas reais, use bibliotecas e protocolos apropriados. Nunca informe senhas pessoais neste laboratório.
